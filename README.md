# D&D Szenenboard – erster Prototyp

Native Android-App für die Session-Vorbereitung.

## Bereits enthalten
- mehrere Szenen zum Durchblättern
- Titel + freie Zeitplanung pro Szene
- unbegrenzte Arbeitsfläche mit Verschieben und Pinch-to-Zoom
- Notizzettel, Textfelder, Bilder und Links
- Elemente frei verschieben
- Elemente über den Griff unten rechts skalieren
- D&D-Beyond-/Weblinks per Doppeltipp öffnen
- Text/Notiz per Doppeltipp bearbeiten
- Bilder über Android-Dateiauswahl einfügen
- automatische lokale Speicherung
- Ansicht „Alles“ passt vorhandene Inhalte ins Sichtfeld ein
- keine Minimap

## Bedienung
- freie Fläche ziehen: Canvas verschieben
- zwei Finger: zoomen
- Element ziehen: verschieben
- Element antippen und Griff unten rechts ziehen: Größe ändern
- Doppeltipp auf Text/Notiz: bearbeiten
- Doppeltipp auf Link: öffnen

## Zielgerät
`minSdk 29` = Android 10.

## Öffnen
Ordner in Android Studio öffnen und Gradle synchronisieren. Falls Android Studio nach einem Gradle Wrapper fragt, diesen einmal erzeugen lassen.
